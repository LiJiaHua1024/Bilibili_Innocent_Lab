# NPatch 阶段 6：使用体验增强

2026-10-23 开始。按 F11 → N3 → F12 → F14 依次交付，每项独立验收并原子提交。正式支持范围沿用阶段 2B；不引入 Shizuku，不把通用业务缺陷或阶段 7 探索项设为前置。

## 6.1 F11 重启引导

复用当前配置/停用 tombstone 的落盘屏障，打开系统应用详情供用户强停。返回设置页后提供明确的“打开并验证”确认，重新落盘当前配置后才拉起宿主，复用当前身份回执确认。系统详情页的返回值不能证明强停；取消返回、进程仍运行、后台/销毁及写入失败不能冒充重启成功。保留 Root 原路径，不引入特权依赖。

验收：实际系统强停后继续打开、取消继续、未强停返回、当前配置确认、失败门控，以及 Manager/embed 对照。

## 6.2 N3 宿主入口与向导

复用已有宿主菜单定位、成员访问与前台宿主发送一次性固定目标 PendingIntent 的启动设施，独立于漫游扩展开关。入口只能去固定 BIL 设置页，保持可见性、有效期、一次性和调用身份验证。首次引导串联现有模式、签名、条款、免 Root 和当前配置诊断，不能把参数符合等同于实际激活；提供可重复打开的入口。

## 6.3 F12 配置热应用子集

先审计回调消费者和安装期限，再冻结白名单。只更新已注册 Hook 的动态读取值，不重装 Hook、不替换启动授权快照、不改变当前运行的启停/条款/安装身份语义。每次更新仍须校验当前端点许可、配置身份和单调 revision；关闭/撤回、旧版本/旧构建、乱序/重复请求与新增子进程不得复用旧许可。未列入子集的设置明确需重启，实际回执才表示热应用成功。

## 6.4 F14 漫游缓存与重启

核查实际漫游实现和缓存校验，再选择安全的同宿主内容复用、完整缓存备份/恢复与首次重建引导。宿主或漫游真实版本/内容变化、损坏缓存必须保留重建路径，不能只靠相同 versionCode 把旧 Hook 点刷新为有效。没有已完成的实际重建证据不自动重启，不承诺所有环境一次重启。

## 实施结果

逐项完成后回填真实构建、快速 Lint、行为/实机证据和限制；复用已通过检查。测试材料保存在忽略目录 `captures/npatch-stage6/`。
### 6.1 F11 结果

有线机 13a7a291：修改前的中断流程保存在 `before/`；embed 返回取消后 PID 仍为空。实际系统强停后 embed PID 11216→13026、Manager 17957→20038，均通过“打开并验证”取得有效回执，截图已人工检查。最终 APK 另做两种模式的系统详情往返、启动/激活和只读真实进程查询，证据在 `f11-final-{manager|embedded}/`；两种模式的产物元数据见 `f11-final-apk/`。不把应用详情返回或 am start 成功单独当成重启确认。

构建与快速 Lint：最终 `f11-message-final/gates.log` 通过（4 分 40 秒，253 Warning，原 3 项错误基线保持）；最终 JVM 回归另跑 39 秒，3800 项，0 失败、0 错误、1 跳过（`f11-jvm-final/`）。首轮沙箱临时文件访问失败保留在 `f11-gates/`，不计通过。没有完整 Lint、Release/R8、Shizuku、push 或分发；标准框架 Root 实机未外推验证。

### 6.2 N3 结果

NPatch 主进程在授权后注册独立 BIL 设置入口，复用既有菜单定位/反射边界和同一组构建/点击 Hook；漫游扩展关闭时仍可使用。按稳定 id 去重，图标复用宿主设置项。前台宿主发送一次性固定目标 PendingIntent，模块接收器只回复凭证，不从后台启动页面；保留调用 UID/包、nonce、有效期、前台可见性和平台启动资格检查。设置 App 不可达/拒绝时仅向仍可见的宿主提示先手动打开设置 App，离开页面不弹迟到提示。

新增三步向导：安装模式/签名/Loader 检查、用户显式开启免 Root、重启与当前回执/诊断。首次识别补丁时展示，也能从兼容设置和宿主入口重开；参数符合、后台限制和实际激活分开描述。正文复用公共皮肤容器/动效，滚动正文留内边距避开圆角裁剪。条款门禁保持在主布局和向导之前。

最终门禁 `n3-recovery-final/gates.log`：Debug/AndroidTest、3800 JVM（0 失败、0 错误、1 跳过）及快速 Lint通过，7 分 44 秒，253 Warning、原 3 项错误基线不变。首轮只因受检弹窗数量由 47 增至 48 而失败；精确更新数量，保留每个弹窗的皮肤/presenter 断言，原失败记录在 `n3-gates/`。新增系统令牌测试验证模块固定目标、不可变/一次性身份及取消语义。

实机证据位于 `n3-final-{manager|embedded}/`，产物/哈希在 `n3-final-apk/`。两种模式均核对三步布局、真实“我的”页唯一入口与两次点击，令牌测试各 4 项。`n3-enable/` 记录实际开关关闭后向导显式开启，开启后不再显示启用按钮，不将“检查中”冒充已激活。向导请求到达已有面板时不覆盖正在进行的用户操作，可从页面入口重开。

一次重复点击在 Instrumentation 完成强停设置进程后超时；系统日志保存了 start/finished instrumentation 的 Force stopping，恢复正常设置页后同一入口再次成功。该次数不计正常启动通过，沿用设置端点不可用时先手动打开 App 的恢复边界，新增明确失败提示。另一次自动化未先滚到“我的”页底部而暂未找到入口，保留原视图树后滚动确认只有一项；没有改定位或伪造点击成功。没有新增依赖、全局后台启动放行、完整 Lint、Release/R8、push 或分发。

最终 embed 首次点击另捕获一次宿主播放服务初始化中断：系统记录固定 MainActivity 启动为 BAL_ALLOW_VISIBLE_WINDOW，随后宿主自行启动 IjkMediaPlayerNoUIActivity 并回到宿主页。原版 8.90.2 该类只负责启动 IjkMediaPlayerService 后 finish（本地单类源码已保存），本轮没有将此现象归因为令牌拒绝或 NPatch 专属缺陷，也没有改通用播放服务。原中断视图树/截图保留；服务初始化稳定后两次真实点击均打开固定向导，最终 embed 令牌 4 项通过，兼容页手动重开向导也通过。此边界单独记录，不把首次中断伪装为通过。
