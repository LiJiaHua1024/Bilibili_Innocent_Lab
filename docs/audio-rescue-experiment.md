# 音频拯救实验

开发基线：`main` 的 `bae163a8`，分支 `experiment/audio-enhance`。

入口：模块设置 → 进阶增强 → 播放 → 音频拯救（实验）。四项独立设置默认关闭，保存后完整重启哔哩哔哩，重新创建播放服务才会采用新配置。设置进入备份目录 v64 和既有授权配置快照，不添加私有配置旁路。

## 已实现

| 功能 | 算法与行为 | 边界 |
| --- | --- | --- |
| 关音菩萨 | 对解码后的采样实时计算左右联动增益；首个超阈值样本立即压制，50 ms 保持、180 ms 平滑释放；慢速基线检测突增，绝对采样峰值上限 −6 dBFS | 不是整体响度均衡，不恢复已削波的录音；没有数秒前瞻，不保证耳机实际声压安全，也不提供过采样真峰值限制 |
| 治好左右耳 | 保留原声道、左右平均为双单声道、自动补齐缺失声道三选一；自动模式要求持续 200 ms、超过约 24 dB 的不平衡，平滑复制正常声道，不提高弱声道增益 | 普通立体声和短暂声像移动保留；单声道平均可能抵消反相信号；这不是对任意不平衡音源的响度自动匹配 |
| 基础底噪抑制 | 80 Hz 高通，50/60/100/120 Hz 陷波，左右联动的低幅下扩展 | 适合电流声、低频轰鸣与较轻底噪；不能消除任意环境声音，轻声讲话可能受影响 |
| 人声清晰度增强 | 180–3800 Hz 语音频段与中侧处理，保留居中声音、衰减两侧音乐及频段外声音 | 不使用源分离模型；居中音乐与居中人声无法分开，偏侧人声也可能变轻；不能声称对所有 BGM 都能提取人声 |

处理顺序：声道修复 → 基础降噪 → 人声清晰度 → 峰值压制。最后一级限制确保前级滤波的过冲也受控。算法不额外排队缓存 PCM 帧，不删帧，不修改播放器时钟、系统音量或播放速度；设备上的实时处理开销仍需验收。

## 接入范围与写入契约

- 仅在 `tv.danmaku.bili:ijkservice` 拦截 `AudioTrack.write`；要求初始化完成、音量流类型 `STREAM_MUSIC`、8–192 kHz、单/双声道及 PCM 8 bit / 16 bit / float。使用 API 3 起的 `getStreamType()`，避免 API 29 才提供的 `getAudioAttributes()` 越过项目 minSdk 27。主进程广告和 UI 音效不接管；其他播放器内核、多声道及压缩直通保留宿主行为。
- 覆盖 byte[]、short[]、float[] 和 ByteBuffer 的六种基础写入形式。时间戳重载不直接注册；只有它继续调用已覆盖的基础写入方法时才会处理。
- 使用私有副本，不改变调用方数组、ByteBuffer 内容或 limit；ByteBuffer 只按实际成功写入的字节数推进 position，PCM 使用本机字节序。数组偏移只在副本上归零。
- 保留 Android 返回的原始计数及错误，部分写入只提交已接收前缀的 DSP 状态；零写入、异常或错误码回滚。PCM 算法为因果处理，因此回滚再重放前缀与一次处理实际接收前缀一致。
- 重载委托有线程内重入保护。每条轨道的写入串行化；flush/stop/release 使用代际失效，不等待阻塞写入锁，避免与用于解除阻塞的宿主操作死锁。轨道使用弱键，值不引用轨道或 Activity。
- 九个必需的写入/生命周期 Hook 全部注册后才启用；注册不完整时已注册回调保持旁路。无效范围、非整帧写入或超过 1,048,576 个原始写入单位的单次请求旁路，不把错误输入重新解释成 PCM。
- 当前主进程诊断显示“未验证”：主进程的安装结果不能证明播放服务已经启动或在处理音频。不得把静态定位、注册成功或模块测试当成宿主运行成功。

Android 写入计数、部分写入和 ByteBuffer position 的依据：[AudioTrack 官方 API 文档](https://developer.android.com/reference/android/media/AudioTrack)。

## 可选项的取舍

提前数秒预警需要已验证的前瞻解码输入及其媒体时间戳。当前只拥有将要送入硬件队列的实时 PCM，没有几秒后的内容，不能提供真实的提前预警。

空白停顿跳过/掠过暂未实现。仅丢弃音频帧或设置 AudioTrack 的倍速，会让视频及宿主时间线不同步；先 seek 一个固定间隔则无法保证不会跳过紧随其后的讲话。因此未添加一个看似可用但不能保证语义的开关。

## 验证方式

DSP 与 PCM 写入事务使用确定性合成信号进行 JVM 测试：首样本尖峰、持续强声、保持与恢复、双耳联动、缺声方向、普通立体声、反相信号、50/60 Hz 及谐波、语音频段、低幅宽带噪声、分块等价性、各采样率、非有限值、堆/直接/只读 ByteBuffer、字节序、原始缓冲区复用，以及部分写入重试。

安装器测试检查默认禁用、进程范围、六种写入入口、生命周期入口及注册失败时的整体旁路。配置测试检查独立启用、非法值归一和备份目录映射。

本轮不连接手机；实机音质、运行时输出格式、蓝牙/有线/扬声器切换、暂停/拖动/换集和与插帧音画补偿的共同运行仍需后续验收。HostLab 静态分析不能代替这些验证。
