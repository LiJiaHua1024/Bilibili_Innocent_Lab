# AI Insight 实验功能

在「实验性功能 → 兼容」启用「AI Insight 视频助手」，沿用同一区域已有的 AI 来源配置。使用下方首个已配置、支持文本生成的 HTTPS 对话模型。修改开关或来源后重启宿主。

启用后，普通 UGC 视频简介列表提供视频总结、Ask、评论话题和 AI 章节四个并列按钮。入口可收起，并随原生简介列表滚动；标题本身不承担隐藏点击动作。打开视频或展开入口不会请求模型，用户选择功能后才读取所需上下文并生成；总结、评论与章节状态各在独立面板呈现，错误提示不会覆盖其他结果。Ask 支持连续提问。无字幕时明确降级到元信息和讨论，不提供情节定位；没有可读取的评论时不发评论总结请求。

「自动生成原生章节」是独立开关，仅在用户主动生成总结后复用其分段，不会在打开视频时触发总结。章节仅适用于没有官方章节、至少 180 秒（3 分钟）且有可用字幕的视频。选择 3 分钟是为了覆盖有明确内容转折的 3～5 分钟教程与知识视频；更短的视频不生成章节。卡片也提供手动生成入口。生成结果通过宿主 `ViewProgressReply → VideoGuide → VideoViewPoint → VideoPoint` 进入原生章节和分段显示，不另画章节列表。章节直接使用生成标题，不附加 `AI · ` 等来源前缀，已有模块缓存也按纯标题渲染，无需重新请求模型。新生成的章节在宿主下次读取播放进度信息时进入播放器；重新打开当前分 P 也可触发。8.90.2 实机已验证原生分段开关、章节面板、当前章节高亮和点击跳转；首轮显示时机仍取决于宿主进度刷新。

## 上下文、Prompt 与输出契约

按照用户提供的 `D:/LLM Engineering/prompt engineering guide.md`，提示词逐句执行删除测试：只有删除后会产生业务歧义的约束才保留，不加入角色身份、激励、通用思考要求或重复格式示例。

| 保留的信息 | 删除后产生的歧义 |
| --- | --- |
| 字幕/作者简介与观众讨论的证据边界 | 将弹幕或评论的观点写成视频事实 |
| 无画面输入、缺失材料与评论样本的范围 | 声称看到了画面，或把少量评论当作整个评论区 |
| `[[t:整数秒]]` 与当前分 P 的定位约定 | 返回无法点击的时间表述，或引用其他分 P |
| 以字幕行号选择分段，代码共享边界 | 模型自行换算时间，或总结与章节独立分段 |
| 材料/历史是数据 | 将字幕或评论中的命令当作任务指令 |

格式优先由 `response_format=json_schema` 承载，未在 Prompt 中再重复一份 schema。仅当服务端用结构化错误明确拒绝该格式时，退回 `json_object` 并附上同一份 schema。输出须通过本地类型、字段、数量、长度、时间范围和字幕覆盖检查，才会渲染或缓存。服务端即使接受 schema 也可能不遵守约束：确定的本地校验失败最多纠正一次，只反馈固定约束和字段路径，不带入上次错误答案；两次生成共享 90 秒模型时限。认证、网络、输出截断、未知错误或无法识别的 JSON 不自动重放，失败不缓存。Insight 单次输出预算为 8192 token，不改变其他 Agent 的默认预算。

River 的 DeepSeek-V4.1-Flash-1017 在默认参数下出现过 JSON 后重复追加、自我改写并耗尽预算。用同一份 310 条合成字幕逐参数实测，`enable_thinking=false` 单独无效，`thinking: {type: "disabled"}` 正常停止；将后者加入现有 `AiChatCompat` 和模型客户端的已验证端点范围，未知端点不猜测该参数。若服务端明确拒绝可选参数，仍使用既有有界回退。该兼容处理不是 Prompt 中的“不要思考”口令。

当前分 P 的全部有效字幕进入总结和 Ask 上下文；每条保留完整文本，不做均匀抽样、关键词窗口筛选或逐条截断。紧凑条目为 `[行号,起秒,止秒,文本]`。当前传输容量为 500,000 字符且 UTF-8 不超过 1,700,000 字节，完整输入超限时停止请求并明确提示，不能静默改用部分字幕；字幕源超过读取容量也使用同一提示。服务端仍可能因自身上下文窗口较小而拒绝请求。

无官方章节且至少 3 分钟、有效字幕不少于 3 行的视频，总结一次生成 overview 与 3～8 个 sections（start_cue、title、summary）。模型选择主题开始的字幕行号，代码取其起秒的整数部分、首章固定为 0，产生总结中的可点击时间及原生章节；因此两者逐项同源，不再分别让模型猜测章节时间。用户先点章节也会复用同一总结生成结果。标题最多 50 字符、每段概括最多 240 字符、概述最多 180 字符。短视频或已有官方章节的视频也使用带字幕行号的 sections（1～8 项），每条概括由代码添加一个前置时间点，不生成或替换原生章节；官方章节保持原样。已有结果缓存兼容显示，尾部相邻引用整理为每条开头一个代表性起点，无需重新调用模型。

Ask 基于完整字幕回答，具体细节可引用章内时间，未要求所有回答都跳到章首；没有画面输入，不能据此识别纯画面细节。最近六轮历史在当前视频内保留全文，不落盘。任务与问题放在材料之后。

总结与 Ask 按已加载顺序最多取前 12 条评论（各 160 字符）及弹幕（各 80 字符）；评论总结最多取 40 条已读取评论（各 400 字符）。宿主评论响应最多保留 40 条去重结果，公开热评接口兜底取首页最多 30 条；弹幕从公开 XML 前 80 条中去重保留最多 40 条。这个范围是确定的有界样本，并非随机抽检，也不代表已抓取整个评论区。评论总结省去字幕和弹幕。无字幕任务不索取片段引用，不提供无助于回答的总时长；简介中的原片时分秒位置省略，其余事实保留，避免误认为当前分 P。

自动化测试覆盖正常、缺失、超长、注入文本、无关材料、格式偏离、时间越界等场景。2026-10-24 另用用户提供的 River 兼容接口和 DeepSeek-V4.1-Flash-1017 做了真实模型、真实视频的端到端验收。样本验证不等同于回答准确率的统计对照评估。

## 缓存与播放器边界

- 协议 v8 使旧版独立生成、可能抽样的缓存失效。总结和章节保存 90 天，评论话题保存 1 小时；磁盘最多 200 条，内存有界。按 BVID、CID、模型端点、模型名、任务和协议版本隔离。
- 先读缓存再加载上下文；成功结果二次打开无需再次请求 B 站或模型。同一仓库实例串行合并重复请求；失败结果不缓存。
- 原始字幕、评论、凭据和 Ask 对话不落盘。生成结果位于宿主私有 `files/bil_insight/`。
- 字幕并行观察宿主 DMMoss 与独立 SubtitleMoss，公开 API 兜底；后台最多等待原生字幕响应 2.5 秒，空响应不覆盖已捕获字幕。标题、评论也可从对应宿主响应提取；快照变化会使已加载上下文失效，避免一直使用未打开评论区时的空样本。字幕下载限定 HTTPS 的 hdslb CDN；原生 HTTP CDN 地址只在域名、端口、用户信息与 fragment 校验后升级到 HTTPS，保留签名查询。不附带模型凭据或宿主 Cookie，不跟随重定向。
- 点击时间前同时检查前台详情 Activity、播放器归属、媒体世代、BVID、CID 和真实播放器时长。复用现有 `SponsorPlayerBindings`、播放器定位器和 `SponsorSeekGuard`，在延迟 seek 真正执行时再次校验。
- 章节封面通过官方 `x/player/videoshot` 获取进度预览：按大端 uint16 解析并移除 bin 头部，选择不晚于章首的最近预览帧，裁剪对应宫格，写入私有 `files/bil_insight_covers/`；`VideoPoint.setCover` 提供本地 URI，由原生列表加载。预览有采样间隔，并非逐帧精确截图；不 seek 播放器、不额外发送画面给模型。队列、尺寸、字节和缓存数量均有界，失败退避 5 分钟；预览接口不可用时保留宿主占位，不阻止章节跳转。
- 原生章节通过独立 builder 复制整条消息链；已有官方章节、默认实例、结构缺失或复制失败时返回原响应，保留其他字段。生成章节打开 `pointPermanent`，让宿主原生分段开关可见。
- 总结分段由字幕行号确定，首章为 0，后续边界相隔至少 10 秒；纯文字字段禁止混入另一个时间标记。Ask 的标记必须完整、无嵌套且在范围内；只通过格式和覆盖检查并不能证明回答的语义准确。字幕起止时间可含小数，播放器跳转使用整数秒：引用与章节统一用 `floor(start)..ceil(end)` 校验覆盖，实际 seek 仍按当前播放器真实时长二次校验。章节不从零开始、间隔不足或没有字幕依据时提供固定校验反馈，仍最多纠正一次。
- 简介入口是原生 UIComponent 列表项，保留宿主 adapter 和原有项；通过已有 KavaMemberLookup 验证组件接口与列表更新方法，稳定字符串作为宿主进程级 view-type 缓存键，不持有 Activity/View。重复数据更新替换旧模块头部而不重复插入。首次插入且原本处于列表顶部时恢复第 0 项；后续更新不打断用户滚动。
- 卡片、按钮和结果面板使用 Lumen 1.5.1 的 LumenFluentControl，包括轮廓、按压、键盘焦点与禁用状态。颜色统一消费 HostChromeTheme 的宿主深浅模式、主题色与个性装扮调色板，移除写死的青绿色。正文使用实色材质维持可读性，滚动回收和面板关闭时释放 Lumen 绑定与主题监听。
